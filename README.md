# ComfyUI-IYKYK

**ComfyUI-IYKYK** 是专为 ComfyUI 设计的东亚人像写真与成人美学提示词生成与冲突消解插件。

> 📌 **项目溯源与致谢**  
> 本项目核心架构与词库规范基于开源项目 [ShuaiHui/nsfw-prompt-templates-asian](https://github.com/ShuaiHui/nsfw-prompt-templates-asian) 深度开发。我们将其定义的 **15 槽位装配流水线**、**7 大冲突消解规则**、**8 大情境亲和矩阵**、**77 套经典预设模板** 与 **服装×裸露联动规范** 完整重构并封装为纯原生、零外部依赖的 ComfyUI 自定义节点套件。

---

## ✨ 核心特性

### 1. 🎴 完整 15 槽位装配流水线
严格遵循项目规范的 15 步装配流水线，按视觉认知与扩散模型注意力机制层层递进：
1. `[场景+主题]` (01-场景主题) — 120+ 空间场景与 47 套经典题材
2. `[景别+视角+设备]` (02-景别构图) — 特写/全景/俯仰视/POV/监控/手机自拍
3. `[裸露状态]` (03-裸露液体) — L1 包裹暗示 至 L6 特写全见
4. `[服装款式与穿脱状态]` (04-服装专项) — 30 类服装 × 12 种脱法状态深度联动
5. `[光影氛围]` (05-光影氛围) — 专业摄影布光、色温、霓虹私密氛围
6. `[姿势动作]` (06-姿势动作) — 跪/坐/卧/站/脱衣/互动等 8 大动作体系
7. `[表情眼神]` (07-表情眼神) — 害羞/诱惑/高潮/服从/恍惚等情绪与视线管理
8. `[风格/胶片/镜头]` (08-风格胶片) — 柯达/富士/电影镜头/天气氛围
9. `[妆容细节]` (09-妆容专项) — 伪素颜/果汁妆/轻熟人妻/魅惑烟熏/泪痕残妆
10. `[发型发色与饰品]` (10-发型饰品) — 黑长直/双马尾/大波浪/湿发/锁骨链/Choker
11. `[真实微瑕与微细节]` (11-瑕疵细节) — 美人痣/真实毛孔/内衣勒痕/透光淡蓝血管
12. `[纹身标记与皮肤融合]` (12-纹身标记) — 耻骨淫纹/极道和彫/正字计数 + 6 词真皮层融合
13. `[道具宠物与环境物件]` (13-道具宠物) — 课本/红酒杯/手机/猫咪/跳蛋/和风红绳
14. `[人格纵深/角色卡片]` (14-人格卡片) — 女高JK/职场OL/女上司/人妻/女教师/小护士
15. `[液体体液系统]` (03-裸露液体) — 微汗晶莹/沐浴水珠/唾液拉丝/爱液痕迹
16. `[画质强化锚点]` (02-景别构图) — 根据拍摄设备自动匹配画质强化词

### 2. 🧠 8 大核心情境亲和度矩阵（Context Affinity）
当槽位设为 `随机 (Random)` 时，插件绝不盲目随机，而是自动感知当前情境并在专属词库中加权采样：
- 🏫 **校园情境**：自动联动水手服、JK校服、双马尾、黑框眼镜、课本、清纯伪素颜
- 💼 **职场情境**：自动联动职场OL西装、包臀裙、黑丝袜、低马尾、红酒杯、轻熟妆
- 🛏️ **居家情境**：自动联动丝绸睡袍、吊带睡裙、凌乱散发、猫咪、抱枕、高潮潮红
- ♨️ **温泉浴室**：自动联动浴衣、和服、湿身泳装、湿发贴脸、沐浴水珠、微汗
- 🌙 **夜店风俗**：自动联动夜店紧身裙、兔女郎装、魅惑烟熏、香槟、身体链
- 🔗 **SM 调教**：自动联动乳胶紧身衣、皮革束腰、和风红绳、金属手铐、耻骨淫纹
- ⛩️ **和风传统**：自动联动正统和服、旗袍、汉服、极道和彫龙、茶具
- 🏥 **医疗诊所**：自动联动白衣护士服、护士帽、听诊器、清纯素颜

---

### 3. 👗 裸露等级 × 服装状态深度咬合
彻底解决「全裸时还穿着衣服」或「包裹时露点」的逻辑矛盾：
- **L1 包裹暗示**：严格封印露点词，服装自动呈现紧身勾勒与微透打湿；
- **L2 差分微露**：解开 1-2 颗纽扣、单侧香肩/吊带滑落、裙摆开叉露腿；
- **L3 半裸诱惑**：纽扣全解露内衣、南半球 (underboob)、侧乳 (sideboob)、裙摆掀起露内裤；
- **L4 重点暴露**：上衣脱掉褪至腰际+保留短裙，或上衣大敞+仅穿内裤；
- **L5 极致全裸**：所有外衣内衣自动转为「散落一旁/地面（`clothes discarded on floor`）」，全身赤裸；
- **L6 特写全见**：私处/双腿间大特写，衣物作为散落背景。

---

### 4. 🛡️ 7 大多规则冲突消解引擎
- **裸露 × 服装互斥**：私处暴露时自动剔除内裤，全裸时自动剔除穿着描述；
- **材质穿透伪影消解**：剔除 `sheer/see-through` 等易崩词，替换为真实物理脱法；
- **视线 × 镜头角度几何对齐**：仰拍强制俯视下看镜头，俯拍强制仰视上看镜头，POV 强制直视对视；
- **视线方向唯一性**：自动消解对视与回避的矛盾；
- **液体微量与安全法则**：自动添加微量量词，彻底拦截眼部精液白内障变形；
- **设备 × 画质兼容性**：监控/手机自拍自动剔除 8K 单反写真词；
- **纹身 6 词真皮层融合**：纹身自动附加真皮层物理融合词，杜绝贴纸漂浮感。

---

### 5. 🎯 纯粹无种子设计与 100% 中文 UI
- **职责清晰**：图像随机性交由 ComfyUI 后置的 `KSampler` 种子掌控；
- **动态抽卡**：内置 `IS_CHANGED` 机制，每次点击 **Queue Prompt** 自动出词；
- **全中文交互**：所有 15 槽位参数、下拉菜单选项与输出端口均提供清晰中文说明。

## 🎛️ 节点套件说明

### 1. 🎴 IYKYK 15槽位提示词生成器 (`IYKYKPromptGenerator`)
全维度的 15 槽位精准控制，每个槽位均可独立选择「无」、「随机」或指定具体项目。

**输出端口**：
- `正面提示词 (STRING)`: 组装、冲突消解、词数裁剪（<250词）后的英文正面提示词
- `负面提示词 (STRING)`: 通用清洗防崩负面词
- `中文场景描述 (STRING)`: 当前画面配置的中文概要说明

---

### 2. 📋 IYKYK 模板浏览器 (`IYKYKPresetBrowser`)
一键浏览与调用 77 套完整手写场景模板（温泉旅馆、教室后排、电车、办公室等），并支持叠加 8 大导演风格配方。

---

### 3. 🧩 IYKYK 自定义槽位拼装器 (`IYKYKCustomSlotCombiner`)
支持自由输入或多节点连接各槽位文本，底层自动执行 7 大冲突消解与画质强化组装。

## 🚀 安装方法

### 方法 1：Git Clone（推荐）
进入 ComfyUI 的 `custom_nodes` 目录并克隆本仓库：

```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/JacobYang/ComfyUI-IYKYK.git
```

### 方法 2：手动下载
下载本仓库 ZIP 压缩包，解压至 `ComfyUI/custom_nodes/ComfyUI-IYKYK` 目录。

重启 ComfyUI 后，在节点右键菜单中即可找到 **`IYKYK / 提示词生成`**。
