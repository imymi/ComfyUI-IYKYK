# ComfyUI-IYKYK

**ComfyUI-IYKYK** 是专为 ComfyUI 设计的东亚人像写真与成人美学提示词生成与冲突消解插件。

> 📌 **项目溯源与致谢**  
> 本项目核心架构与词库规范基于开源项目 [ShuaiHui/nsfw-prompt-templates-asian](https://github.com/ShuaiHui/nsfw-prompt-templates-asian) 深度开发。我们将项目定义的 **16 步装配流水线**、**8 大冲突消解引擎**、**8 大核心情境亲和矩阵**、**77 套经典预设模板** 与 **服装×裸露脱法联动规范** 完整重构并封装为纯原生、零外部依赖的 ComfyUI 自定义节点套件。

> 🤖 **AI 辅助开发声明 (AI-Assisted Development Statement)**  
> 本项目的代码架构、数据清洗与重构、冲突消解算法、情境亲和引擎及 ComfyUI 原生节点实现由人类开发者与 AI (Google DeepMind Antigravity / Gemini) 协同开发完成。

## ✨ 架构与核心特性

### 1. 🎴 流水线槽位体系规范
为了向用户与开发者提供精准的工程概念，本项目明确区分三层槽位口径：
- **15 用户可配置控件**：场景大类、剧情主题、景别构图、拍摄视角、裸露等级、服装款式与状态、发型发色、饰品头饰、妆容细节、姿势动作、情绪表情、光影预设、胶片风格、液体效果、纹身标记、道具物件、角色设定、真实微瑕、画质等级。
- **16 步视觉认知流水线**：按扩散模型注意力机制层层递进（场景空间 → 景别视角 → 角色设定 → 裸露状态 → 服装穿脱 → 光影氛围 → 姿势动作 → 表情眼神 → 妆容细节 → 发型饰品 → 微瑕质感 → 纹身标记 → 道具环境 → 液体系统 → 胶片影调 → 画质锚点）。
- **18 项内部流水线调度槽位 (`SLOT_PIPELINE_ORDER`)**：底层通过 `PromptFragment` 数据结构承载 18 个细分装配槽位与空间互斥组（`exclusive_group`）。

---

### 2. 🛡️ 8 大多规则冲突消解引擎 (`PromptFragment` 结构化管道)
- **空间与物理环境自洽互斥**：全部 122 个场景子分类具备稳定 ID 与唯一 `exclusive_group`，按输入顺序锁定首个主场景，杜绝「温泉与餐厅并存」、「室内温泉与露天雪景并存」等跨空间矛盾；
- **裸露 × 服装脱法咬合**：私处暴露时自动剔除内裤，全裸（L5/L6）时自动剔除穿着描述并将衣物转换为散落背景；
- **材质穿透伪影消解**：剔除 `sheer/see-through` 等易崩词，替换为真实物理脱法；
- **视线 × 镜头角度几何对齐**：仰拍强制俯视下看镜头，俯拍强制仰视上看镜头，POV 强制直视对视；
- **视线方向唯一性**：自动消解对视与回避的矛盾；
- **液体微量与安全法则**：自动添加微量量词，彻底拦截眼部精液白内障变形；
- **设备 × 画质兼容性**：监控/手机自拍自动剔除 8K 单反写真词；
- **纹身 6 词真皮层融合**：严格作用于纹身槽位，杜绝 `pink` / `drink` / `link` 等词汇引发误触发。

---

### 3. 🧠 8 大核心情境亲和度矩阵（Context Affinity）
当槽位设为 `随机 (Random)` 时，插件绝不盲目随机，而是自动感知当前情境并在专属词库中加权采样（覆盖校园、职场、居家、温泉、夜店、SM、和风、医疗等 14 大细分情境）：
- 🏫 **校园情境**：自动联动水手服、JK校服、双马尾、黑框眼镜、课本、清纯伪素颜
- 💼 **职场情境**：自动联动职场OL西装、包臀裙、黑丝袜、低马尾、红酒杯、轻熟妆
- 🛏️ **居家情境**：自动联动丝绸睡袍、吊带睡裙、凌乱散发、猫咪、抱枕、高潮潮红
- ♨️ **温泉浴室**：自动联动浴衣、和服、湿身泳装、湿发贴脸、沐浴水珠、微汗
- 🌙 **夜店风俗**：自动联动夜店紧身裙、兔女郎装、魅惑烟熏、香槟、身体链
- 🔗 **SM 调教**：自动联动乳胶紧身衣、皮革束腰、和风红绳、金属手铐、耻骨淫纹
- ⛩️ **和风传统**：自动联动正统和服、旗袍、汉服、极道和彫龙、茶具
- 🏥 **医疗诊所**：自动联动白衣护士服、护士帽、听诊器、清纯素颜

---

### 4. 🎯 确定性可复现与 ComfyUI 原生 Seed 支持
- **可复现 `prompt_seed`**：
  - 设置为 `-1` 时：保留动态随机抽卡（`IS_CHANGED` 触发动态刷新）；
  - 设置为非负整数时：100% 确定性复现当前生成，并启用 ComfyUI 结果缓存。
- **括号权重语法保护**：自定义输入支持 `(masterpiece:1.2)`, `[blouse:sweater:10]`, `<lora:name:0.8>`，顶层解析保护内部逗号与转义逗号 `\,`。
- **统一 250 词上限**：三类生成入口全面接入统一 `finalize_prompt`，在完整片段边界截断，防止未闭合语法。

## 🎛️ 节点套件说明

### 1. 🎴 IYKYK 15槽位提示词生成器 (`IYKYKPromptGenerator`)
全维度的 15 槽位精准控制，每个槽位均可独立选择「无」、「随机」或指定具体项目。

**输出端口**：
- `正面提示词 (STRING)`: 组装、冲突消解、词数裁剪（<250词）后的英文正面提示词
- `负面提示词 (STRING)`: 通用清洗防崩负面词
- `中文场景描述 (STRING)`: 当前画面配置的中文概要说明

---

### 2. 📋 IYKYK 模板浏览器 (`IYKYKPresetBrowser`)
一键浏览与调用 77 套完整手写场景模板（温泉旅馆、教室后排、电车、办公室等），并支持叠加 8 大导演风格配方。

---

### 3. 🧩 IYKYK 自定义槽位拼装器 (`IYKYKCustomSlotCombiner`)
支持自由输入或多节点连接各槽位文本，底层自动执行 8 大冲突消解与画质强化组装。

## 🚀 安装方法

### 方法 1：Git Clone（推荐）
进入 ComfyUI 的 `custom_nodes` 目录并克隆本仓库：

```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/imymi/ComfyUI-IYKYK.git
```

### 方法 2：手动下载
下载本仓库 ZIP 压缩包，解压至 `ComfyUI/custom_nodes/ComfyUI-IYKYK` 目录。

重启 ComfyUI 后，在节点右键菜单中即可找到 **`IYKYK / 提示词生成`**。
